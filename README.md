**Суть приложения**

Трекер привычек — инструмент для формирования и контроля регулярных действий. Пользователь создаёт список привычек (например, «пить воду», «читать 30 минут»), а приложение помогает следить за их выполнением и видеть прогресс.

Основной функционал:
- **Главный экран** — список всех привычек: название, описание, счётчик выполненных сегодня («3 из 5») и переключатель-чекбокс, который отмечает привычку выполненной за конкретный день. Отметки сохраняются автоматически в локальное хранилище.
- **Добавление и редактирование** — создание новой привычки (название до 50 символов, описание до 200) или изменение существующей; при редактировании доступно удаление вместе со всеми отметками.
- **Статистика** — лента последних 7 дней: для каждого дня показывается, выполнялась ли хотя бы одна привычка, плюс сводка за неделю (дни с прогрессом и общее число отметок).

**Технологический стек**

- **Язык:** Dart.
- **Фреймворк:** Flutter (Material 3), тёмная тема с красными акцентами.
- **База данных:** SQLite через пакет `sqflite`; для поддержки настольных платформ (Windows/Linux) используется `sqflite_common_ffi`.
- **Платформы:** Android, iOS, web, Windows, macOS, Linux (генерируются автоматически через `flutter create`).
- **Дополнительно:** локальное хранилище вместо серверного — данные привычек и отметок выполнения хранятся на устройстве пользователя.
